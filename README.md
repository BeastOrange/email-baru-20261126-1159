# Make the AI Judge Laugh Entry

## Overview
This program deterministically writes an entry for the "Make the AI Judge Laugh" competition by outputting a single-line joke to `/output/entry.txt`.

## How to Run
Run the program with:

```bash
python3 main.py
```

## Joke Criteria Targeted
- **Surprising turn**: An open-concept floor plan backfires in the most awkward way possible.
- **Punchline at the end**: The reveal lands in the final words.
- **Tight one-liner**: Delivered in a single compact sentence with immediate comedic timing.
- **Original**: A fresh take on home renovation regret.
